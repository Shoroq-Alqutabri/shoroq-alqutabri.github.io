# Shorouq Alqutabri — Professional Portfolio

Production-ready static portfolio/CV website built with semantic HTML, modern CSS and lightweight JavaScript.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages compatible
- No backend required

## Before publishing
1. Replace the placeholder GitHub Pages URL in `robots.txt` and `sitemap.xml`.
2. Verify the email, phone number and GitHub URL against your current professional details.
3. Add a real professional headshot to `assets/images/` only if desired.
4. Enable GitHub Pages from the repository settings.
